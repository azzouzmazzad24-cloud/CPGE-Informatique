## Première année — MPSI, PCSI et TSI 1

Les deux progressions de première année transmises présentent la même répartition thématique.

| Mois | Séquences prévues | Formats mentionnés dans les documents |
|---|---|---|
| **Septembre** | Codage des entiers (bases 2, 16, complément à deux) ; codage des réels (virgule fixe et flottante) | Cours, TD |
| **Octobre** | Introduction à Python : variables, affectation, entrées/sorties, opérations et commentaires ; structures alternatives | Cours, TD, TP |
| **Novembre** | Structures répétitives (`for`, `while`, `break`, `continue`), boucles imbriquées | Cours, TD, TP |
| **Décembre** | Fonctions, modules, `return`, portée, assertions, récursivité simple ; introduction à la terminaison/correction | Cours, TD, TP |
| **Janvier** | Terminaison et correction (TD) ; listes et manipulations | Cours, TD, TP |
| **Février** | Listes : recherche, tri par comptage, tris quadratiques | Cours, TD, TP |
| **Mars** | Chaînes de caractères ; dictionnaires, tuples, ensembles ; piles/files | Cours, TD, TP |
| **Avril** | Piles/files et `collections.deque` (suite) ; fichiers | Cours, TD, TP |
| **Mai** | Bibliothèques scientifiques (`numpy`, `scipy`, Matplotlib) ; traitement d'images | Cours, TP |
| **Juin** | Ingénierie numérique : zéros de fonctions, intégration numérique, EDO | Cours, TP |

### Parcours d'activités suggéré (proposition pédagogique, non issu des PDF)

1. **Découvrir :** observer un exemple exécuté, prédire son résultat et identifier les nouveaux concepts.
2. **Manipuler :** modifier un programme court dans un notebook Jupyter.
3. **Expliquer :** justifier la correction d'une expression, d'une boucle ou d'un traitement.
4. **Réinvestir :** réaliser un exercice progressif puis un mini-TP.
5. **Évaluer :** vérifier les acquis par questions courtes et exercice de synthèse.
